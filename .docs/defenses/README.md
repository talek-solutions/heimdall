# Solution defenses

Each significant change defended before it was built, kept once it was approved or rejected.
One defense per file, numbered. A defense is edited while `Proposed` and frozen after it is
decided. A later change of mind is a new defense that supersedes it.

The process is bifrost's
[`process/solution-defense.md`](../../../bifrost/process/solution-defense.md), and the template is
[`process/templates/solution-defense.md`](../../../bifrost/process/templates/solution-defense.md).
